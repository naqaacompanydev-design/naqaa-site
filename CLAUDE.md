# Naqaa Cleaning website (naqaa-cleaning.com)

Static site on Vercel (Arabic RTL + English under `/en/`). No framework: pages are plain
HTML files. Several parts are **generated by scripts in `tools/` and `build_blog.py`**:
edit the source and re-run the script, never hand-edit the generated output.

## Adding a blog article (do exactly this)

1. **Create it from the template** (never copy an existing article: existing articles are
   already converted, so the build would skip yours and keep the old table of contents,
   reading time and related links):

   ```bash
   python3 tools/new_article.py \
     --slug water-tank-summer-riyadh \
     --title "تنظيف الخزان في الصيف: متى وليش؟" \
     --short-title "تنظيف الخزان في الصيف" \
     --description "وصف لجوجل في حدود 150 حرف" \
     --excerpt "سطرين يظهروا تحت عنوان الكارت في المدونة" \
     --section water-tanks \
     --category "تنظيف الخزانات • نصائح" \
     --cover path/to/cover.jpg --cover-alt "وصف الصورة"
   ```

   - `--slug`: English, lowercase, words joined by `-`, usually ending in `-riyadh`.
   - `--section` must be one of (see `tools/blog_sections.py`):
     `homes` (منازل وفلل وشقق ومجالس), `facilities` (منشآت وشركات ومكاتب ومساجد ومدارس ومطاعم…),
     `water-tanks` (خزانات), `prices` (أسعار), `choosing-a-company` (اختيار الشركة، ثقة، ضمان، تقييمات),
     `pest-control` (حشرات).
   - The cover can be jpg/png; the build makes a WebP copy (the jpg stays for social previews).

   This creates `blog/<slug>/index.html` and adds the article at the top of `articles.json`.

2. **Write the content** in `blog/<slug>/index.html`, between the
   `محتوى المقالة: ابدأ من هنا` and `محتوى المقالة: انتهى` comments. Replace every `TODO`.
   - Intro in the `intro-box`, then sections as `<h2>` + `<p class="reveal">`.
   - Ready components: `tip-box`, `warn-box`, `check-list`, `steps-list`, FAQ (`faq-list`/`faq-item`),
     examples are in the comment at the top of the content.
   - One `<h1>` only (it is already in the template). Don't add a table of contents, reading time,
     booking box or related links: the build adds them.
   - Writing style: Saudi dialect, friendly, practical, Riyadh-specific. No made-up prices,
     statistics, reviews or discounts. Current offers: only the contract discounts and the mosque
     discount that already exist on the site.
   - Extra images go in the article folder; reference them relatively (`<img src="name.jpg" alt="...">`).

3. **Build** (from the repo root):

   ```bash
   python3 build_blog.py
   ```

   One command does everything: checks every article, converts the new one (WebP images, FAQ
   structured data, new layout with table of contents, reading time and booking box), rebuilds
   `/blog/` and `/blog/page/N/`, the section pages `/blog/category/<slug>/`, the related-article
   cards at the end of every article, adds the URL to `sitemap.xml`, and runs final checks.
   If it stops with ✗, fix what it lists and run it again. It is safe to run any number of times.
   Requires Python 3 and Pillow (`pip install pillow`) for the WebP step.

4. Preview (open a PR; Vercel posts a preview link) and ask the owner before merging to `main`
   (merging publishes the site).

To change an article's section, card text or image: edit its entry in `articles.json`, then run
`python3 build_blog.py`. To change the text of a published article: edit its page directly (the
content area only), then run `python3 build_blog.py` so listings and related cards stay in sync.

## Generated files: edit the source, then re-run

| Output | Source | Command |
|---|---|---|
| `/blog/`, `/blog/page/N/`, `/blog/category/*/`, related cards, blog sitemap entries | `articles.json`, `blog_templates/*.html`, `tools/blog_*.py` | `python3 build_blog.py` |
| `/en/pricing/` (English price calculator) | `pricing/index.html` (prices + logic) and `tools/pricing_en_strings.py` (English text) | `python3 tools/build_pricing_en.py` |

- Prices live only in `pricing/index.html`. After changing them, run `tools/build_pricing_en.py`;
  it stops if any new Arabic text has no English translation: add it to `tools/pricing_en_strings.py`.

## House rules

- Images: use WebP for page images (keep the jpg/png next to it for `og:image`).
- Keep each file's existing line endings (some files are CRLF).
- Every page has the fixed contact bar (`#nq-fbar`: WhatsApp / احسب سعرك / اتصل) and the
  Google Analytics + Tag Manager + Clarity snippet at the top of `<head>`.
- New pages go in `sitemap.xml`; Arabic/English pairs get `hreflang` links.
- Commit messages and PRs in English; talk to the owner in Egyptian Arabic.
